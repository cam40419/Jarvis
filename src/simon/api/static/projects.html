    Project models
    
          
    
            
            
          
    
        
    
        
    
          Choose an approved provider or local endpoint and connect a project key when required.
          Adding a model makes no model call. Qualification checks basic text and JSON responses; it
          does not certify research, creative work, or tools.
        
    
        
      
        
      
          
      
            
      Routing and resource limits
      
            
      
              
              
            
      
          
      
          
      
          
      
          
      
            Every call must fit both the project and workspace limits. Amounts are USD; daily and
            monthly windows use UTC. Unknown charges and their call slots remain reserved until
            resolved. Local calls still consume concurrency.
          
      
        
      
        
      
          
      Usage history
      
          
      
            Generation, review and qualification appear separately. Usage is based on the configured
            token rates and the provider's reported counts.
          
      
          
        
          
        
        
      
        
      
        
        
        Add project model
        
        
        
          
        
            
          
        
          
        
          
        
            
          
        
          
        
            
            
            
        
              Stored encrypted for this project. The key is cleared from this form when submitted
              and is never shown again. Leave blank when editing to keep the current key.
            
        
          
        
          
          
        
            Changing a key or enabling a model requires a new qualification before use. Disabling it
            blocks new calls; incurred usage remains recorded.
          
        
        
        
      
        
      
        
        
        Project settings
        
        
        
          
        
            
        
              
        
                
              
        
              
        
                
              
        
            
        
            
        
              Automatic routing selects an eligible qualified model within these permissions.
              Selecting a model pins the route; an unavailable selection blocks the call. A
              dispatched call never silently falls back to another model.
            
        
            
            
          
        
          
        
            
        
              
            
        
            
        
              
            
        
          
        
          
        
            
        
              
            
        
            
        
              
            
        
          
        
          
        
            An operation includes all reserved calls, such as planning and its review. Zero allows
            calls with zero configured fees only. These limits do not purchase compute or pay a
            provider invoice.
          
        
          
        
            
          
        
          
        
        
      
        
      
        
        
        Qualify model
        
        
        
        
        
          This sends one synthetic request without project documents. A successful check qualifies
          basic text and structured JSON at the current model and credential revision. It is not a
          broader quality assessment.
        
        
        
        
          
        
        
      
        
      
        
        
        Reconcile unknown charge
        
        
        
        
        
          Use provider records to determine the total charge for this call. This replaces its held
          amount with the recorded charge and preserves your evidence in the audit history. It does
          not refund the provider.
